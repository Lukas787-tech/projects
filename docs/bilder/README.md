# Beispielbilder

Hier kommen die Beispielbilder für den Abschnitt „Beispiele“ hinein.

So wird ein Platzhalter in `../index.html` ersetzt:

```html
<figure class="example">
  <img src="bilder/DATEINAME.jpg" alt="Kurze Beschreibung des Bildes">
  <figcaption>
    <strong>Beispiel 1 · Hände</strong>
    Was genau auf dem Bild auffällt.
  </figcaption>
</figure>
```

Hinweise:
- Dateinamen klein und ohne Leerzeichen (z. B. `haende-01.jpg`).
- Möglichst JPG oder PNG, Breite ca. 1200 px reicht aus.
